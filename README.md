# Markdown Learner

A calm, minimal research reader for a folder of Markdown notes, built with Tauri.

Read a page. Select text to ask a question. Get a quick answer inline, open a new page beside the one you are reading, or send a deep dive to load in the background. Every new page is a plain `.md` file written back into the same folder.

Status: under construction. See `docs/` for the architecture and `design/` for the Claude Design source files this app implements.
