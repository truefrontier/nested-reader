# Does replay run the other way?

Yes. Reverse replay was first reported in awake rats pausing at the end of a track (Foster and Wilson, 2006). The place-cell sequence unfolds backwards from the animal's current position, as if rewinding the route just run.

Reverse replay is most common right after reward and is sensitive to how large the reward was. That pattern fits a credit-assignment role: the brain replays the path backwards from the outcome so that the steps closest to the reward are strengthened most.

Forward replay, by contrast, is more common before a run begins and during sleep, which fits planning and consolidation. The two directions may be the same machinery used for two different jobs.
