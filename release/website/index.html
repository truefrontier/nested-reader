A plan for
background jobs

Our product turns customer interviews into searchable research. A long interview can hold a request open for several minutes.

How it would work

The upload endpoint saves the file, creates a job, and returns immediately. A worker picks up the job and updates its progress.

Jobs should be idempotent: processing the same job more than once must not create duplicate results.

Ask about this

The question behind the plan

A queue changes when work happens. It doesn’t remove the need to make that work safe to repeat.

Your question

What does idempotent mean here?

Think of a job as a request with a name tag.

If the same request arrives twice, the worker recognizes it and returns the existing result. It doesn’t create a second one.

In your plan: a stable job ID and a database constraint protect against duplicate results.

Install on Mac

Move Nested into Applications,
then open it once.

Nested is unsigned preview software. macOS Gatekeeper will ask you to confirm the first launch.

  1. Download Nested for Apple silicon and unzip it.
  2. Move Nested.app into Applications. Leaving it in Downloads can trigger App Translocation and break local data paths.
  3. Open Nested. If you see “Nested.app” Not Opened, choose Done (not Move to Trash).
  4. System Settings → Privacy & Security — scroll to the Nested.app message and click Open Anyway.
  5. In the follow-up dialog Open “Nested.app”?, choose Open Anyway again (not Move to Trash).
  6. Approve with Touch ID or an administrator password when macOS asks.
  7. Connect AI. Paste an OpenAI API key, or use Use local Codex API key when Codex on this Mac already has an API key. A ChatGPT subscription login alone is not enough for GPT-6 Astra.
A few useful answers

Before you open
the next layer.

What can I open in Nested?

Markdown and plain-text files, folders of documents, or a pasted response. A sample architecture review is included so you can explore the reader immediately.

Is this another chat app?

Nested starts with your document. Questions attach to passages, explanations become connected pages, and a book map keeps the relationship between them visible. Your reading remains the center of the experience.

How does the AI work?

Every AI feature uses GPT-6 Astra (gpt-6-astra) through the OpenAI Responses API. Paste an API key with access to that model, or import a key from a local Codex API-key login. A ChatGPT subscription session alone cannot call this API. Usage is billed by OpenAI. There is no silent fallback to another model.

Where does my work go?

Your book is saved as local Markdown with local metadata. When you ask a question, the relevant document context is sent to OpenAI. Research may read additional pages in the current book. Nested does not publish or share your library.

What does it cost?

This build is a bring-your-own-key preview. Paste an OpenAI API key, or import one from local Codex when available. There is no Nested subscription. ChatGPT Plus/Pro does not replace API billing for Nested. OpenAI charges for API use.

Where is the source code?

Nested is open source. The Mac app (Electron Astra build on the astra branch, Tauri on main) lives at github.com/truefrontier/nested-reader. The marketing site is github.com/truefrontier/nestedreader.app.

Can I use it on my Mac?

Yes. Download the Apple silicon app, move it into Applications, and open it. If macOS blocks the first launch, use System Settings → Privacy & Security → Open Anyway. The preview is not Developer ID signed or notarized. The public /app page is install guidance only — the reader runs in the Mac app.
